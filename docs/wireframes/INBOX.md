# LifeOS — Inbox Wireframe

## עיקרון מוביל

ה־Inbox צריך להיות המקום הכי מהיר ופשוט ב־LifeOS.

המטרה היא לא לתכנן.

המטרה היא:

> להוציא דברים מהראש עכשיו, ולהחליט עליהם אחר כך.

> Capture first. Organize later.

## סדר החשיבות במסך

1. Capture מהיר
2. הדברים שמחכים להחלטה
3. פעולות עיבוד מהירות
4. עריכה ופרטים נוספים

המסך לא צריך להרגיש כמו Task Manager.

---

## הוספה מהירה

שדה ההוספה נמצא תמיד בחלק העליון.

המשתמש יכול להקליד:

```text
לקבוע טיפול לרכב
```

וללחוץ:

```text
Enter
```

הפריט נשמר מיד.

לא נפתח טופס.

לא נדרש לבחור תאריך.

לא נדרש לבחור קטגוריה.

---

## פריט Inbox

כל פריט מציג מינימום מידע:

```text
כותרת
מתי נוסף
פעולות מהירות
```

לדוגמה:

```text
לקבוע תור לרופא

נוסף היום, 10:32

[ היום ] [ השבוע ] [ לבחור יום ] [ ••• ]
```

---

## פעולות מהירות

שלוש הפעולות השכיחות צריכות להיות זמינות בלי לפתוח את הפריט:

### היום

```text
Inbox → Today
```

המשימה נכנסת לתכנון של היום.

---

### השבוע

```text
Inbox → Week
```

המשימה שייכת לשבוע הנוכחי, אך עדיין ללא יום.

---

### לבחור יום

פותח בחירת תאריך פשוטה:

```text
ראשון  9/8
שני   10/8
שלישי 11/8
...
```

לאחר הבחירה:

```text
Inbox → Selected Day
```

---

## פעולות נוספות

בתפריט:

```text
•••
```

יופיעו פעולות פחות שכיחות:

* עריכה
* הוספת פרטים
* השאר ב־Inbox
* מחיקה

פעולות שאינן עיקריות לא צריכות ליצור עומס ויזואלי.


המטרה היא לייצר תחושת ניקיון, לא חגיגת "Inbox Zero".

---

## Inbox עמוס

כאשר הצטברו פריטים רבים:

```text
23 דברים מחכים למיון
```

אפשר להציג פעולה:

```text
[ מיין כמה עכשיו ]
```

הניסוח לא יהיה:

```text
23 משימות שלא טיפלת בהן
```

LifeOS לא משתמשת באשמה כדי לגרום למשתמש לפעול.

## מצב עיבוד מהיר

לא חייב להיכנס לגרסה הראשונה, אבל נשמר כחלק מהכיוון.

```text
┌──────────────────────────────────────────┐
│ 3 מתוך 18                               │
│                                          │
│        לקבוע טיפול לרכב                  │
│                                          │
│   [ היום ]                               │
│   [ השבוע ]                              │
│   [ לבחור יום ]                          │
│   [ מחק ]                                │
│                                          │
│                    דלג ←                 │
└──────────────────────────────────────────┘
```

לאחר בחירה, הפריט הבא מופיע מיד.

## Capture גלובלי

בעתיד ניתן יהיה להוסיף פריט מכל מקום במערכת.

לדוגמה:

```text
+
```

או:

```text
⌘ + K
```

ואז:

```text
מה צריך לזכור?
[ ______________________________ ]
```

ברירת המחדל:

```text
Save to Inbox
```

אלא אם המשתמש בוחר יעד אחר.

## החלטות ראשוניות

* Capture הוא הדבר הראשון במסך.
* יצירת פריט חדש דורשת כותרת בלבד.
* Inbox הוא אזור מעבר ולא רשימת ביצוע.
* הפעולות Today / Week / Date נגישות ישירות.
* פרטים נוספים הם אופציונליים.
* לא יוצרים עותק חדש כשמעבירים משימה.
* Inbox ריק הוא מצב חיובי ושקט.
* לא מציגים מדדי פרודוקטיביות במסך הזה.

---

## שאלות פתוחות

* האם שלוש הפעולות המהירות צריכות להיות מוצגות תמיד או רק ב־hover/selection.
* האם מובייל יציג Bottom Sheet לעיבוד הפריט.
* האם ניתן יהיה לבחור כמה פריטים ולעבד אותם יחד.
* האם Inbox יציג רק תאריך יצירה או גם כמה זמן הפריט מחכה.
* האם בעתיד יהיה Capture של Note שלא הופך למשימה.
* האם `⌘ + K` יהיה Capture ישיר או Command Palette כללי.

---

## תנאי הצלחה

המשתמש צריך להיות מסוגל להכניס דבר חדש ל־LifeOS בתוך שניות.

ולאחר מכן, בזמן שמתאים לו, לעבור על ה־Inbox ולהחליט במהירות:

```text
עכשיו?
השבוע?
ביום אחר?
או בכלל לא?
```

בלי למלא טפסים ובלי להרגיש שהוא מתחזק מערכת.
